# Data model

This reference describes the SQL schema after migrations `0001` through `0008`. All primary identifiers are UUIDs generated by `gen_random_uuid()` except `audit_events.id` and `job_logs.id`, which are `bigserial`.

## Ownership and relationships

Most operational tables contain `owner_id uuid not null default auth.uid()`. It is deliberately not a foreign key to `auth.users`; RLS uses `owner_id = auth.uid()` for dashboard visibility. A project owns tasks, artifacts, jobs, approvals, and evidence through foreign keys. `audit_events.project_id` is deliberately **not** a foreign key so history can survive project deletion unchanged.

| Table | Purpose | Relationships |
|---|---|---|
| `projects` | Canonical project metadata and its primary file location pointer. | Parent of tasks, artifacts, jobs, approvals, evidence. Referenced by audit events only as a non-FK identifier. |
| `agents` | Registered local/cloud/future agent definitions and declared operating scope. | Referenced by tasks, jobs, and approvals; deletion sets those optional references to null. |
| `tasks` | Work items and optional parent/subtask hierarchy. | Belongs to a project; optionally assigned to an agent; self-references a parent task; referenced by artifacts, jobs, evidence. |
| `artifacts` | Generated or referenced project output metadata. | Belongs to a project; may belong to a task; may be output of a job; may support evidence. |
| `jobs` | Executable work record, status, timing, errors, and idempotency. | Belongs to a project; may point to task, agent, and output artifact; parent of approvals and job logs; may be linked by evidence. |
| `approvals` | Exact consequential-action requests and human decisions. | Belongs to a project; may identify requesting agent and job; action type is known policy. |
| `evidence` | Source/provenance records supporting project work. | Belongs to a project; may point to task, job, and artifact. |
| `audit_events` | Append-only lightweight change history. | Stores owner, actor, entity identifiers, and optional project identifier; no foreign keys after migration 0008. |
| `job_logs` | Structured per-step messages for a job. | Belongs to a job; cascade-deleted if the job is deleted. |
| `action_policies` | Authoritative action-type risk and automatic/approval policy. | `jobs.job_type` and `approvals.action_type` foreign-key to `action_type`. |
| `system_settings` | Singleton-like system settings such as pause and recorded autonomy level. | No foreign keys. |

## Tables and columns

### `projects`

Purpose: a project, its status, tags, ownership, and canonical location pointer.

| Column | Type | Notes |
|---|---|---|
| `id` | `uuid` | Primary key; defaults to `gen_random_uuid()`. |
| `owner_id` | `uuid` | Not null; defaults to `auth.uid()`; no Auth foreign key. |
| `name` | `text` | Not null; must not be blank. |
| `slug` | `text` | Not null; unique with `owner_id`. |
| `description` | `text` | Optional. |
| `status` | `project_status` | Not null; default `active`. |
| `priority` | `priority_level` | Not null; default `medium`. |
| `tags` | `text[]` | Not null; default empty array. |
| `canonical_location` | `text` | Optional pointer to the primary location. |
| `location_kind` | `location_type` | Not null; default `local_path`. |
| `is_demo` | `boolean` | Not null; default `false`. |
| `created_at` | `timestamptz` | Not null; default `now()`. |
| `updated_at` | `timestamptz` | Not null; default `now()`; touch trigger updates it. |
| `archived_at` | `timestamptz` | Optional. |

## Views

All three views use `security_invoker = true`, so the caller's RLS permissions apply.

### `v_pending_approvals`

One row per pending approval, ordered newest first. Columns: `id`, `project_id`, `project_name`, `job_id`, `action_type`, `risk_level`, `action_preview`, `target_reference`, `requested_by`, `requested_at`, `expires_at`, `is_stale`. It joins approvals to projects and optionally agents.

### `v_job_activity`

One row per job, ordered newest first. Columns: `id`, `project_id`, `project_name`, `job_type`, `risk_level`, `auto_allowed`, `status`, `attempt_count`, `max_attempts`, `agent_name`, `queued_at`, `started_at`, `finished_at`, `duration_seconds`, `output_artifact_id`, `error_summary`. It joins jobs to projects and action policy, optionally to an agent.

### `v_project_summary`

One row per non-archived project. Columns: `id`, `name`, `slug`, `status`, `priority`, `tags`, `is_demo`, `updated_at`, `open_tasks`, `done_tasks`, `artifact_count`, `evidence_count`, `active_jobs`, `failed_jobs`, `pending_approvals`. Counts are correlated subqueries over the related tables.
